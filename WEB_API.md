# Browser and CLI contract (0.1.0)

`@austindelic/blackhole` exports `mountBlackHole(element, options)` and public option/camera/controller types. No React import in the root. Options retain the source renderer's quality, backend, rendererMode, ASCII, exposure, bloom, camera and animation settings. Controller: `ready: Promise<boolean>`, `update(partialOptions)`, `setCamera({position?, forward?, universeSign?})`, `pause()`, `resume()`, `resize()`, `dispose()`. Host must have a nonzero size. Disposal removes only owned DOM. Errors render visibly and call optional `onError(message|null)`. `routes` accepts a per-instance Record<string, BlackHoleRouteAnimation>; `animationRoute` explicitly selects the preset, with no automatic portfolio URL routing. Defaults retain the authored home camera. `onReady` optional. `paused` requests a still frame; pause retains redraws on settings/camera/resize. `getStats()` returns per-instance diagnostics when debugStats is true. React entry `/react` exports named `BlackHole`, with the same options plus `className` and `style`; no CSS framework required. React is an optional peer. Shaders embedded in JS; `/shaders/*` and `/routes.json` compatibility exports retained.

CLI: `@austindelic/blackhole-cli`, bin `blackhole`. `add --framework react|vanilla --out-dir src/blackhole [--dry-run] [--overwrite]` installs editable TypeScript and embedded shader sources generated from canonical package source. Detects React in Vite/Astro dependencies. `explore ...args` launches `@austindelic/blackhole-{platform}-{arch}/bin/blackhole[.exe]`. `ghostty --out-dir PATH` copies bundled GLSL and prints config without changing active config. Canonical CLI integration source is `integrations/ghostty/blackhole.glsl` (site task owns this); CLI build copies it into its package. Node >=22. No runtime downloads.
